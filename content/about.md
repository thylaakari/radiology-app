# О программе

Приложение создано для врачей-рентгенологов и помогает вести рабочие записи, оформлять протоколы исследований и работать с данными пациентов в одном интерфейсе. Основной сценарий использования — повседневная клиническая работа, где важны скорость, понятная структура и доступ к данным даже без постоянного подключения к сети.

## Назначение

Программа предназначена для врачей, которым нужен удобный инструмент для описания исследований и организации повседневной работы. Она подходит для локальной работы на рабочем месте, когда важно быстро открыть пациента, заполнить протокол и сохранить данные без лишних шагов.

## Что делает программа

- Помогает создавать и редактировать протоколы исследований в удобном рабочем формате.
- Позволяет вести карточки пациентов и структурировать рабочие данные.
- Поддерживает офлайн-сценарий работы за счёт локального хранения данных.
- Может использовать онлайн-Supabase как серверную часть для сетевых возможностей и дальнейшей синхронизации.

## Преимущества

Главное преимущество программы — ориентация на практическую работу врача-рентгенолога, а не на абстрактный «медицинский софт». Приложение развивается как отдельный рабочий инструмент на базе Tauri и Nuxt, с локальным хранением через IndexedDB/Dexie и возможностью опираться на онлайн-Supabase там, где нужны серверные функции.

## Для кого подходит

Программа рассчитана прежде всего на врачей-рентгенологов. Она будет полезна специалистам, которым нужен аккуратный, быстрый и понятный инструмент для ежедневной работы с протоколами и пациентами без перегруженного интерфейса.

## Развитие проекта

Проект находится в активной разработке и развивается как радиологическое приложение с отдельным сайтом для лендингов, релизов, новостей и доставки установочных файлов. Это позволяет разделить собственно рабочее приложение и внешний информационный контур проекта.
